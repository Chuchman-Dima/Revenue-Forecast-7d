# Прогноз доходу за 7 днів (Revenue Forecast 7D)

Проєкт з data science для прогнозування доходу користувача на наступні 7 днів на основі параметрів користувачів і поведінкових логів.

## Основна мета

- підготувати дані до моделювання;
- створити набір ознак на основі активності користувача;
- навчити прогнозну модель для оцінки ймовірності покупок і суми доходу;
- порівняти кілька алгоритмів для вибору найкращого підходу;
- сформувати готовий датасет для подальшого використання в навчанні та оцінці моделей.

## Що реалізовано в проєкті

- EDA та перевірка якості вхідних даних;
- feature engineering для ознак користувача та його поведінки;
- побудова двоетапної Hurdle-моделі:
  1. прогнозування ймовірності покупки;
  2. прогнозування суми доходу для покупців;
- порівняння метрик кількох моделей: CatBoost, LightGBM, XGBoost, Random Forest;
- формування фінального датасету `data/final_data.csv`.

## Основний підхід до моделювання

Основна складність полягає в сильному дисбалансі класів: більшість користувачів не генерують дохід.

Рішення: двоетапна Hurdle-модель:
1. Класифікація: прогноз ймовірності того, що користувач зробить покупку.
2. Регресія: модель оцінює суму доходу лише для користувачів, які придбали щось.
3. Фінальний прогноз: `P(покупка) × прогнозована_сума`.

## Порівняння моделей

| Алгоритм | MAE | Примітки |
|-----------|-----|----------|
| CatBoost | ~0.94 | Найкращий баланс точності класифікації та регресії |
| LightGBM | ~1.15 | Близький другий, швидше навчання |
| XGBoost | ~1.15 | Схожий результат до LightGBM |
| Random Forest | Вище | Базовий еталон |

## Запуск проєкту

1. Клонуйте репозиторій:
```bash
git clone https://github.com/Chuchman-Dima/Revenue-Forecast-7d.git
cd Revenue-Forecast-7d
```

2. Встановіть залежності:
```bash
pip install -r requirements.txt
```

3. Розмістіть вхідні CSV-файли в папці `data/`:
   - `task_2_users_params.csv`
   - `task_2_users_actions.csv`

4. Запустіть ноутбуки в такому порядку:
```bash
jupyter notebook src/ipynb/model.ipynb
```

Цей ноутбук виконує:
- EDA;
- feature engineering;
- навчання Hurdle-моделі;
- генерацію `data/final_data.csv`.

```bash
jupyter notebook src/ipynb/comparison_of_models.ipynb
```

Цей ноутбук:
- завантажує підготовлений датасет `final_data.csv`;
- проводить бенчмаркінг алгоритмів;
- порівнює метрики продуктивності.
